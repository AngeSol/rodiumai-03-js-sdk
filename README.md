# RodiumAI – script avec le SDK JavaScript (Exercice 3)

Même script que l'exercice 2 (chat → image → vidéo, menu *précédent / rester / suivant*),
avec le paquet npm `rodiumai`.


```bash
npm run probe     
npm start
```

Menu après chaque étape : `p` précédent, `r` rester, `s` suivant, `q` quitter.
